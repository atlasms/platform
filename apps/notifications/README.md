# @atlas/notifications

Inboxes: tasks, messages and notifications, delivered by permission.

Generated by `nx g @atlas/generators:service notifications --db --broker`. What the scaffold gives you and why is in
[`tools/generators/README.md`](../../tools/generators/README.md); this file is about the service.

## What it owns

What lands in a person's inbox — tasks, messages and notifications — lifted from
`reference/notifications-service` (EP-25.1). Design: `docs/architecture/services/notifications.md`
(§13a is what is built); contract: `docs/architecture/openapi/notifications.yaml`.

- **Consumes** `workflow.task.created` (BMS) → a **task**, one row whoever it is offered to (a user, a
  group or a role); `asset.expired` (MAM) → a **re-review-due notification** for the approver whose
  approval lapsed. Each event is one unit of work — seen-mark, row, and what it announces
  (`task.created` + `audit.recorded`, or `notification.raised`) in one transaction.
- **Serves** `GET /api/v1/inbox` — the caller's own, nobody else's.
- **Store**: a port (`InboxStore`) with a sqlite and a Postgres adapter held to one conformance suite
  (`src/store-conformance.ts`), driven through the service.

## Run

```sh
npx nx test @atlas/notifications        # in memory, no infrastructure
npm run k8s:up                          # builds atlas/notifications:dev and deploys it with the rest
kubectl -n atlas logs deployment/notifications -f
```

Routed by the gateway at `/api/v1/inbox`, `/tasks`, `/messages`, `/notifications` and `/preferences`
(`productionRoutes`, held to the contract by `apps/api-gateway/test/routes.test.ts`).

## Configuration

| Variable              | Default                            |                                              |
| --------------------- | ---------------------------------- | -------------------------------------------- |
| `PORT` / `HOST`       | `3000` / `0.0.0.0`                 |                                              |
| `ATLAS_IAM_ORIGIN`    | `http://iam:3000`                  | Critical readiness dependency                |
| `ATLAS_PG_URL`        | `postgres://…@postgres:5432/atlas` | Waited for at startup, within a 120 s budget |
| `ATLAS_NATS_URL`      | `nats://nats:4222`                 | Retried, never a readiness check             |
| `ATLAS_OTLP_ENDPOINT` | _(unset: no export)_               | ADR-0004                                     |
