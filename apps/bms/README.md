# @atlas/bms

Business process management: workflow definitions, and (EP-22.3) their running instances on Temporal.

Generated by `nx g @atlas/generators:service bms --db --broker`. What the scaffold gives you and why is in
[`tools/generators/README.md`](../../tools/generators/README.md); this file is about the service.

## What it owns

Workflow definitions (EP-22.2) — authored as drafts, validated, published as immutable versions —
and their **instances**, run on Temporal (EP-22.3, [ADR-0010](../../docs/adr/0010-bms-durable-runtime.md)):
[bms.md §13a–13b](../../docs/architecture/services/bms.md), the contract
[`bms.yaml`](../../docs/architecture/openapi/bms.yaml). The validator is `@atlas/contracts/workflow`.

| File                                |                                                                                           |
| ----------------------------------- | ----------------------------------------------------------------------------------------- |
| `src/workflow.ts`, `src/service.ts` | Definitions: drafts, CAS on `revision`, validate, publish; instances: start, read, signal |
| `src/engine/`                       | The pure interpreter over the `Effects` boundary (lifted from `reference/bms-workflow`)   |
| `src/temporal/`                     | The generic Temporal workflow, its activities, the worker and client (`runner.ts`)        |
| `src/runtime.ts`                    | What the activities do — idempotent, tested without a server                              |
| `src/runner-inprocess.ts`           | The interpreter run in-process: what the HTTP tests start instances with                  |
| `src/store*.ts`                     | The port, its sqlite and Postgres adapters, and the conformance suite both pass           |
| `bundle.mjs`                        | The workflow code bundled at IMAGE build; prunes the SDK's foreign native cores there     |

Its image is `node:24-slim`, not Alpine — the SDK's native core is glibc-only (AGENTS.md §6).

## Run

```sh
npx nx test @atlas/bms        # in memory, no infrastructure
ATLAS_TEMPORAL_ADDRESS=localhost:7233 npx nx test @atlas/bms   # + the worker on a real Temporal
npm run k8s:up                          # builds atlas/bms:dev and deploys it with the rest
kubectl -n atlas logs deployment/bms -f
```

Reachable inside the cluster as `http://bms:3000`, and through the gateway at `/api/v1/workflows`
and `/api/v1/instances` (`productionRoutes`, held to `bms.yaml` by the gateway's routes test).
