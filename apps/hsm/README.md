# @atlas/hsm

The Hierarchical Storage Manager: the file ledger and every operation on stored bytes.

Generated by `nx g @atlas/generators:service hsm --db --broker`. What the scaffold gives you and why is in
[`tools/generators/README.md`](../../tools/generators/README.md); this file is about the service.

## What it owns

The file ledger — the [File record](../../docs/architecture/schemas/file.schema.json) as system of
record — the storage targets, and every operation on stored bytes. The design is
[`hsm.md`](../../docs/architecture/services/hsm.md) and the decisions
[ADR-0009](../../docs/adr/0009-hsm-storage-and-placement.md); the contract is
[`hsm.yaml`](../../docs/architecture/openapi/hsm.yaml).

- `driver*.ts` — the storage port, the `fs` and `s3` drivers, and the suite both pass.
- `targets.ts` — storage targets as data; credentials read from the mounted Secret, never stored.
- `file.ts`, `service.ts` — placement (signed over the file's SHA-256, streamed), location, copy /
  move / delete / release as leased operations.
- `store*.ts` — the ledger, replicas, targets and the operation queue: sqlite and Postgres, one
  conformance suite driven through the service with real bytes.

Only HSM mounts the storage volume and the storage credentials — `npm run k8s:check` fails otherwise.

## Run

```sh
npx nx test @atlas/hsm        # in memory, no infrastructure
npm run k8s:up                          # builds atlas/hsm:dev and deploys it with the rest
kubectl -n atlas logs deployment/hsm -f
```

Reachable inside the cluster as `http://hsm:3000`. To route it through the gateway: an origin in
its config and a row in its table, **both in `apps/api-gateway/src/main.ts`** (not `routing.ts` — that
is a test fixture), the env in `infra/k8s/base/api-gateway.yaml`, and once it is proxied a probe in the
smoke suite's upstream gate (`infra/smoke/smoke.test.mjs`).

## Configuration

| Variable                       | Default                            |                                                                                                 |
| ------------------------------ | ---------------------------------- | ----------------------------------------------------------------------------------------------- |
| `PORT` / `HOST`                | `3000` / `0.0.0.0`                 |                                                                                                 |
| `ATLAS_IAM_ORIGIN`             | `http://iam:3000`                  | Critical readiness dependency                                                                   |
| `ATLAS_PG_URL`                 | `postgres://…@postgres:5432/atlas` | Waited for at startup, within a 120 s budget                                                    |
| `ATLAS_NATS_URL`               | `nats://nats:4222`                 | Retried, never a readiness check                                                                |
| `ATLAS_OTLP_ENDPOINT`          | _(unset: no export)_               | ADR-0004                                                                                        |
| `ATLAS_HSM_FS_BASE`            | `/storage`                         | An fs target's root must lie under it — the storage mounted into HSM                            |
| `ATLAS_HSM_BOOTSTRAP_ROOT`     | `/storage/online`                  | The platform's first online target, made once when there is none                                |
| `ATLAS_HSM_CREDENTIALS_DIR`    | `/var/run/atlas/hsm-credentials`   | `<credentialRef>/accessKeyId` and `/secretAccessKey`, from the `hsm-storage-credentials` Secret |
| `ATLAS_HSM_INTERNAL_KEYS`      | _(unset: every placement refused)_ | The keys producers sign with (`hsm-internal-keys`; ADR-0008/0009)                               |
| `ATLAS_HSM_READ_KEYS`          | _(unset: readers refused)_         | Keys accepted on the availability route ONLY (`hsm-read-keys`; Scheduling, EP-31)               |
| `ATLAS_HSM_WORKER_INTERVAL_MS` | `1000`                             | How often the operation worker looks for due work                                               |
